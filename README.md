# Random-Quote-Generator

## Автор
Андреюк Александр

## Возможности
- Генерация случайных цитат
- Фильтрация по автору и теме
- Добавление новых цитат (с валидацией)
- Сохранение и загрузка истории (JSON)

## Примеры использования
1. Нажмите «Сгенерировать цитату».
2. Введите фильтр по автору или теме и примените его.
3. Добавьте свою цитату в поля внизу.
4. История цитат сохраняется автоматически.
